# 환경 세팅
- Docker 설치 권장
- python : 3.12
- mysql : 8.4

## venv 가상환경 세팅

```bash
python -m venv 2nd_project
source .venv/bin/activate
pip install -r requirements.txt
```

## Anaconda 가상환경 세팅
```bash
conda create --name 2nd_project python=3.12 -y
conda activate 2nd_project
pip install -r requirements.txt
```

## Docker MySQL 실행
```bash
docker compose up
```
## 패키지 버전 갱신
```bash
pip freeze > requirements.txt
```

`pip freeze > requirements.txt`를 실행하면 현재 가상환경에 설치된 패키지 목록으로 `requirements.txt`가 덮어써진다.

따라서 필요한 패키지가 빠지지 않도록 먼저 설치 상태를 확인해야 한다.

```bash
pip install python-dotenv PyMySQL mysql-connector-python
pip freeze > requirements.txt
```

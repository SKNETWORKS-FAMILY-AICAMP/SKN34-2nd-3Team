| 감소율 모델 선정 | 감소율 예측을 위한 딥러닝·머신러닝 모델 중 특정 모델이 압도적으로 높은 설명력이나 정확도를 보이지 않아 최적 모델 선정에 어려움을 겪었다. 딥러닝 활성화 함수로 ReLU, LeakyReLU, GELU, SiLU를 각각 적용해 비교했지만 뚜렷한 최적 모델을 찾지 못해, 최종적으로 오차율이 가장 낮은 머신러닝 Random Forest 모델을 선택했다. | — |
| 감정분석 데이터셋 대상 정제 | 최초 댓글 감정분석 데이터셋에 작가 댓글, 독자 댓글에 대한 작가 답글, 일반 대댓글, 유료 회차 댓글이 포함되어 실제 독자 반응과 관계없는 데이터가 감정 분포와 모델 성능을 왜곡할 가능성이 있었다. 분석 대상을 `무료 회차 AND 텍스트 댓글 AND 원댓글 AND 작가가 작성하지 않은 댓글 AND 빈 댓글이 아님`으로 재정의해 데이터셋을 재구성했다. 작가 댓글과 답글은 원본 데이터에 보존하되 감정분석 학습·평가 대상에서는 제외했다. | — |
| 댓글 데이터 작품 편향 | 초기 댓글 데이터가 댓글이 많은 일부 인기 작품과 특정 회차에 집중되어 특정 작품의 문체·독자층·반복 표현을 과도하게 학습할 위험이 있었다. 작품을 랜덤 또는 분산된 ID로 선택하고 작품당 댓글 수 상한, 대표 회차 선택, 작품·회차별 균등 제한 기준을 적용하는 수집·샘플링 방향을 설계했다. 또한 동일 작품이 학습·검증 데이터에 함께 포함되지 않도록 작품 단위 분리를 검토하여 작품 편향을 낮추고 다양한 장르와 독자 표현을 반영할 수 있게 했다. | — |
| 감정분석 모델 실사용 검증 | 파인튜닝 모델의 라벨 순서와 실제 출력 확률을 검증했다. 명확한 긍정·부정 문장은 정상적으로 분류했지만 중립 표현을 긍정으로 판단하는 사례를 발견했으며, 중립 데이터 보강과 임계값 조정이 필요한 개선 사항으로 정리했다. | — |
